1. Coloque **uma única cópia** de `Atividade_Cap11_produtos_agricolas(2).csv` em `dados/` na raiz do projeto (o GitHub não armazena o CSV).
2. Instale as dependências com `python -m pip install -r requirements.txt` e abra o notebook no Jupyter.
3. Confira os dados do grupo, a redação e as referências; após qualquer edição local, reexecute todas as células em ordem.
