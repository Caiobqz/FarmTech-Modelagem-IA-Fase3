### Como executar a versão do GitHub

1. Obtenha o CSV original da atividade FIAP.
2. Coloque **somente uma cópia** do arquivo em `dados/`, ao lado do notebook ou na pasta pai. Arquivos `Atividade_Cap11_produtos_agricolas*.csv` ou `produtos_agricolas*.csv` são reconhecidos.
3. Instale as dependências com `python -m pip install -r requirements.txt`, a partir da raiz do repositório.
4. Abra o notebook no Jupyter e execute todas as células em ordem.

O CSV não foi publicado neste repositório público. Em contrapartida, **o notebook individual de entrega privada** incorpora uma cópia integral compactada desse CSV e foi executado em ambiente sem arquivos externos (16/16, sem erros). A versão privada deve ser enviada diretamente à plataforma da FIAP, e não publicada no GitHub ou distribuída em grupos.
